## 🎨 Customization Guide

### Change Colors
Edit `style.css`:
```css
/* Main colors */
:root {
    --primary: #64c8ff;
    --secondary: #ff64c8;
    --background: #0a0e27;
}
```

### Add Sections
Edit `index.html`:
```html
<section class="new-section">
    <div class="container">
        <!-- Your content -->
    </div>
</section>
```

### Modify Animations
Edit `script.js`:
```javascript
// Change animation speeds
const animateValue = (element, start, end, 2000);
//                                          ^ milliseconds
```
